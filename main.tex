\begin{abstract}
Knee magnetic-resonance imaging (MRI) classification is difficult when trusted structured labels are scarce, radiology reports are abundant but incomplete, and each examination contains a heterogeneous set of pulse sequences. We present \code{CNN\_CPC}, a PyTorch framework for leakage-aware weakly supervised, multi-sequence, study-level knee MRI classification. The released development surface contains 4,407 studies and 24,371 MRI series; 58 studies carry complete labels for twelve target abnormalities, while the remaining 4,349 studies are primarily supervised through their reports. The pipeline combines competition-only MRI representation learning, multilingual structured report states, six semantic MRI streams, distributed 2.5D ConvNeXt-Tiny features, a cross-sequence Transformer, and twelve interacting pathology queries. A frozen report parser converts every report/target cell to positive, negated, uncertain, or unmentioned; report silence is never treated as a negative label. Direct weak supervision uses 3,120 report-only studies containing 14,123 usable target cells and excludes all 58 gold studies from the training gradient and early stopping. Increasing weak-training coverage from approximately 1.28 nominal corpus passes to four complete passes improved macro ROC AUC from 0.5398 to 0.5645 on the repeatedly used 58-study development set. Two subsequent controlled ablations were negative. A 2$\times$2 spatial-token model reached 0.5301. A label-free metadata audit then identified 552 historical cross-contrast stream substitutions among 21,886 selected training streams; strict semantic routing eliminated these inconsistencies but reached only 0.5335. The paired B9--B7.1 bootstrap difference was $-0.03024$ with 95\% interval $[-0.06794,0.00703]$, and only 5.62\% of valid replicates favored strict routing. These results retain the simpler full-coverage B7.1 model and show that semantic purity alone does not guarantee improved predictive ranking when it removes potentially informative acquisitions. The software also provides geometry-aware DICOM ordering, metadata repair, robust intensity normalization, decoding audits, checkpoint provenance, test-time augmentation, bootstrap uncertainty, paired model comparison, and single-GPU runtime protection. Because the same 58 studies have informed repeated development choices, all reported scores are model-selection/development estimates rather than independent hidden-test performance.

\section{Introduction}
\label{sec:introduction}

Magnetic-resonance imaging provides complementary information about knee ligaments, menisci, cartilage, bone, synovium, and joint fluid through multiple anatomical planes and pulse sequences. Deep learning has demonstrated the feasibility of examination-level knee MRI classification, with MRNet providing an influential multi-series baseline \cite{bien2018mrnet}. Modern convolutional encoders such as ConvNeXt \cite{liu2022convnext} and attention-based sequence models \cite{vaswani2017attention} make it possible to integrate evidence from many slices and acquisitions. In the present setting, however, network capacity is not the only limiting factor. The central methodological problem is how to learn twelve target classifiers when structured labels are scarce, free-text reports are incomplete, MRI acquisition protocols vary substantially, and the same small gold set must be protected from direct training leakage.

CNN\_CPC was developed around five principles. First, reports are training supervision rather than inference inputs. Second, report silence is not a negative label. Third, MRI sequence roles and missing acquisitions are represented explicitly. Fourth, gold studies do not enter weak-training gradients or early stopping. Fifth, each development change is named, frozen before evaluation, and compared with aligned study-level bootstrap resampling so that post-hoc tuning on the 58-study development set remains visible.

The current repository evolved through a controlled ladder. Competition-only MRI self-supervision improved the random neural baseline. Image--report representation alignment produced a stronger frozen representation. Structured report states then enabled direct pathology-specific weak supervision. Complete weak-corpus coverage produced the strongest standalone development model, B7.1. Two later hypotheses were tested and rejected: retaining coarse within-slice spatial tokens with fixed anatomy priors (B8), and enforcing exact fluid/structural sequence semantics (B9). The negative B9 result is especially informative because it demonstrates that a metadata inconsistency can be real while the corresponding correction still reduces predictive performance. This manuscript documents both the software and the complete measured B0--B9 development evidence available in package 0.14.0.

\section{Problem definition and data contract}
\label{sec:problem}

\subsection{Targets}
For each study $i$, the model predicts $\hat{\mathbf y}_i\in[0,1]^{12}$ for ACL, MCL, medial meniscus, lateral meniscus, medial osteoarthritis, lateral osteoarthritis, patellofemoral osteoarthritis, effusion, synovitis, Baker's cyst, contusion, and fracture. The primary metric is the macro average of target-wise ROC AUC values.

\subsection{Released data surface}
The verified release used here contains 4,407 training studies, 58 fully labelled gold studies, 4,349 report-only studies, and 24,371 series rows. All 58 gold studies contain all twelve official target values. The report-only pool is used for competition-only representation learning and weak image supervision. The gold set has supported repeated method choices and is therefore a development/model-selection set rather than a pristine independent test set.

\subsection{Series metadata}
Each MRI-series row contains \code{StudyInstanceUID}, \code{SeriesInstanceUID}, \code{Fluid\_Sensitive}, \code{Fat\_Suppression}, and \code{Anatomical\_Plane}. Populated CSV metadata are treated as authoritative. Missing plane or contrast metadata can be recovered from DICOM geometry and timing information, but DICOM inference is used only as fallback rather than silently replacing supplied competition metadata.

\section{DICOM ingestion and preprocessing}
\label{sec:dicom}

Selected DICOM objects are decoded with pydicom. When \code{ImageOrientationPatient} and \code{ImagePositionPatient} are available, slice order is determined by the image-plane normal
\begin{equation}
\mathbf n=\mathbf r\times\mathbf c,
\end{equation}
and scalar coordinate $z=\mathbf p\cdot\mathbf n$. \code{InstanceNumber} is used as a fallback. Multi-frame objects are expanded deterministically.

Pixel values are rescaled using $x'=ax+b$, with DICOM rescale slope and intercept. MONOCHROME1 is inverted. The finite 1st and 99th percentiles are used for clipping and normalization,
\begin{equation}
\tilde{x}=\frac{\operatorname{clip}(x',q_{0.01},q_{0.99})-q_{0.01}}
{\max(q_{0.99}-q_{0.01},10^{-6})},
\end{equation}
after which frames are resized to $224\times224$ pixels.

A full historical selected-series audit decoded all 21,886 selected series. Of 732,556 candidate DICOM files, 732,554 decoded and two failed. The two affected series each lost only one instance and remained below the configured partial-corruption threshold; no selected series was discarded.

\section{Semantic MRI streams}
\label{sec:routing}

\subsection{Six-stream representation}
Each knee is represented by up to six roles:
\begin{align*}
&\text{sagittal-fluid},\quad \text{sagittal-structural},\\
&\text{coronal-fluid},\quad \text{coronal-structural},\\
&\text{axial-fluid},\quad \text{axial-structural}.
\end{align*}
Missing streams are represented by zero tensors together with an explicit presence mask so they do not participate as real tokens.

\subsection{Historical dual selector and metadata audit}
The historical B7/B7.1 selector attempted to populate both semantic slots in a plane when several acquisitions were available. If multiple acquisitions belonged to only one contrast class, one acquisition could therefore be assigned to the opposite semantic slot. A label-free audit over the full 4,407-study training metadata found 552 such mismatches among 21,886 selected streams (2.52\%).

\subsection{B9 strict semantic routing}
B9 requires
\begin{align}
\text{fluid slot} &\Rightarrow \code{Fluid\_Sensitive=True},\\
\text{structural slot} &\Rightarrow \code{Fluid\_Sensitive=False}.
\end{align}
If the required contrast class is absent, the stream remains missing rather than receiving an opposite-contrast substitute. The historical router is retained unchanged for B7.1 reproducibility; B9 uses a separate implementation and records a label-free routing audit in its checkpoint artifacts.

\section{Distributed 2.5D representation}
\label{sec:25d}

For a decoded series of $N$ frames, $S=16$ center positions are distributed approximately uniformly through the valid range. With triplet gap $g$, a center $c_s$ produces
\begin{equation}
X_s=[I_{c_s-g},I_{c_s},I_{c_s+g}].
\end{equation}
Evaluation uses $g=1$. Training samples $g\in\{1,2\}$ and allows center jitter of up to two slices. The nominal tensor is $[B,6,16,3,224,224]$. Mild augmentation includes rotation, translation, scale jitter, gamma perturbation, multiplicative bias field, Gaussian noise, and slice dropout. A bounded worker-local cache reduces repeated DICOM decoding.

\section{Competition-only representation learning}
\label{sec:representation}

\subsection{Strong MRI self-supervision}
The strong MRI self-supervised checkpoint used only the 4,349 non-gold competition studies and no external image weights. It completed eight epochs, 8,000 batches, and 24,000 study draws, approximately 5.52 nominal corpus passes. Relative to random initialization, the strong SSL initialization improved macro development AUC from 0.4763 to 0.5030.

\subsection{B5 image--report alignment}
B5 aligned the competition-only MRI encoder with report semantics represented by TF--IDF word 1--2 grams, truncated SVD, and $\ell_2$ normalization. No external language model was used. B5 excluded all 58 gold studies from representation learning. Under the unchanged frozen downstream probe,
\begin{equation}
\mathrm{AUC}_{\mathrm{macro}}=0.5243650851,
\end{equation}
with 95\% bootstrap interval $[0.4728108406,0.5761619105]$. B5 became the encoder initialization for B7/B7.1/B9.

\section{Structured weak supervision from reports}
\label{sec:reports}

For each target, the frozen B6 v1.2.1 parser assigns one of four states:
\begin{equation}
r_{ic}\in\{\mathrm{positive},\mathrm{negated},\mathrm{uncertain},\mathrm{unmentioned}\}.
\end{equation}
Unmentioned and uncertain cells are ignored for direct B7-family supervision. The frozen report-only export contains 3,120 active studies and 14,123 usable target cells: 6,871 positive and 7,252 negated.

A completed gold audit over 251 usable report/target cells yielded TP=116, TN=80, FP=52, and FN=3, corresponding to positive precision 0.6905, sensitivity 0.9748, specificity 0.6061, NPV 0.9639, and balanced accuracy 0.7904. This motivated one global asymmetric policy rather than target-specific tuning:
\begin{center}
\begin{tabular}{lcc}
\toprule
B6 state & Soft target & Base weight \\
\midrule
positive & 0.85 & 0.50 \\
negated & 0.05 & 1.00 \\
uncertain & ignored & 0.00 \\
unmentioned & ignored & 0.00 \\
\bottomrule
\end{tabular}
\end{center}
Target-wise multipliers equalize total weak-supervision mass across the twelve outputs. B6 parser rules and this global policy are frozen after the audit.

\section{Pathology-query MRI classifier}
\label{sec:model}

Each active 2.5D triplet is encoded by ConvNeXt-Tiny \cite{liu2022convnext}, yielding $d=768$ features. For stream $k$ and position $s$,
\begin{equation}
\mathbf h_{ks}=M_k(\mathbf f_{ks}+\mathbf p_s+\mathbf e_k),
\end{equation}
where $M_k$ is the stream-presence mask and $\mathbf p_s$, $\mathbf e_k$ are learned position and stream embeddings. The $6\times16=96$ tokens are passed through a two-layer, eight-head Transformer encoder with feed-forward width $2d$ and dropout 0.25.

Twelve learned pathology queries first interact through a one-layer Transformer and then cross-attend to the MRI memory. If $Q$ denotes the pathology queries and $H$ the MRI memory,
\begin{equation}
A=\operatorname{MHA}(Q,H,H),
\end{equation}
followed by residual normalization and target-specific linear readout. B7.1 and B9 use this globally pooled architecture.

B8 tested an alternative that retained a $2\times2$ final ConvNeXt spatial grid for each slice, increasing MRI memory from 96 to 384 tokens/study, together with fixed gentle pathology-specific stream/slice attention priors.

\section{B7-family optimization}
\label{sec:optimization}

B7-family weak training uses target-balanced binary cross-entropy with the frozen B6 soft targets and weights. Let $w_{ic}$ be the base weak-label weight and $m_c$ the fixed inverse supervision-mass multiplier. The loss is
\begin{equation}
L=\frac{\sum_{i,c}m_cw_{ic}\,\ell_{\mathrm{BCE}}(z_{ic},y_{ic})}
{\sum_{i,c}m_cw_{ic}}.
\end{equation}
Encoder and head initial learning rates are $10^{-5}$ and $10^{-4}$, respectively, with AdamW, weight decay $10^{-4}$, gradient clipping at 1.0, and cosine annealing to $10^{-6}$. Batch size is two.

B7-v1 was capped at 500 batches/epoch for four epochs, yielding 4,000 study draws in total. B7.1 changed only the cap to 1,560 batches/epoch. Thus every complete epoch draws all 3,120 active studies and exposes all 14,123 usable weak cells once. Four epochs therefore provide four nominal full-corpus passes. B9 keeps this B7.1 optimization contract and changes only routing semantics.

\section{Statistical evaluation and development policy}
\label{sec:evaluation}

For every target with both classes represented, ROC AUC is computed and macro AUC is
\begin{equation}
\mathrm{AUC}_{\mathrm{macro}}=\frac{1}{12}\sum_{c=1}^{12}\mathrm{AUC}_c.
\end{equation}
All twelve target AUCs are defined on the 58-study development set.

Uncertainty uses study-level bootstrap resampling. B7.1, B8, and B9 use 5,000 replicates. For paired comparison of aligned models $A$ and $B$, the same resampled study indices are used:
\begin{equation}
\Delta_b=\mathrm{AUC}_{B,b}-\mathrm{AUC}_{A,b}.
\end{equation}
We report the median $\Delta$, percentile 95\% interval, and the fraction of valid replicates with $\Delta>0$.

The 58 studies have supported repeated sequential decisions. Consequently, the experiment ladder is model-selection/development evidence. A point estimate or paired probability is not interpreted as independent hidden-test proof, especially when the paired 95\% interval crosses zero.

\section{Runtime and execution policy}
\label{sec:runtime}

Competition mode uses one requested GPU with CPU multiprocessing for DICOM/data work. The software budget is 8.5 h with a 10-min reserve. Long stages checkpoint after completed epochs and record whether the budget limited the run. B7.1, B8, and B9 all completed their predefined four-epoch training contracts without budget truncation on the NVIDIA RTX A4500 Laptop GPU used for the local experiments.

The primary neural evaluation uses center offsets $[-1,0,1]$. Multiple views are generated from the same decoded volume and probabilities are averaged. Runtime-only DataLoader changes, such as disabling persistent workers for a final evaluation, do not alter the scientific model or TTA contract.

\section{Discussion}
\label{sec:discussion}

The experiment ladder yields several consistent conclusions. First, representation quality matters. Competition-only MRI self-supervision and subsequent image--report alignment improved on the random neural baseline. Second, direct pathology-specific report supervision was more useful than representation alignment alone. B7-v1 improved on B5, and complete weak-corpus coverage in B7.1 produced the strongest standalone development estimate. Third, additional architectural complexity is not automatically beneficial: the spatially richer B8 model optimized smoothly but generalized worse than the simpler 96-token B7.1 representation.

The B9 result adds a less obvious lesson. The historical router did contain a genuine metadata inconsistency: hundreds of acquisitions were assigned to stream roles that contradicted the supplied fluid-sensitivity flag. Strict routing corrected this perfectly. Nevertheless, predictive ranking deteriorated. This shows that eliminating a semantic inconsistency and improving the training objective are not sufficient evidence of improved generalization. A plausible interpretation is that the historical fallback sometimes supplied an additional informative acquisition even when its semantic embedding was imperfect, whereas strict routing converted those cases into missing streams. This interpretation is supported by the fact that B9 reduced the active training-stream count by 442, while the gold input itself changed very little. However, this mechanism remains an inference rather than a demonstrated causal explanation and should not be turned into a post-hoc hybrid on the same 58 labels.

The paired result also illustrates why point estimates should not be overinterpreted. B9 was lower than B7.1 by approximately 0.031 macro AUC and 94.38\% of paired bootstrap replicates favored B7.1, yet the 95\% interval still extended slightly above zero. With only 58 studies and repeated development use, uncertainty remains substantial. The appropriate decision is therefore operational rather than absolute: retain B7.1, close B9-v1, and avoid claiming that semantic routing can never help on a larger independent set.

Weak-label reliability remains another important limitation. The B6 audit showed high sensitivity and NPV but lower positive precision, motivating globally asymmetric weak supervision. Synovitis in particular has very few explicit negative report cells, so target-specific conclusions are unstable. The parser is deterministic and can miss unusual multilingual phrasing. These issues argue for better supervision sources in future experiments rather than repeated optimization of the same 58-study evaluation surface.

Other limitations include the metadata-driven six-stream abstraction, incomplete preservation of three-dimensional geometry by 2.5D triplets, lack of explicit physical PixelSpacing normalization before resizing, and the absence of an independent hidden-test result at the current manuscript snapshot. These limitations should guide the next generation of experiments.

\section{Future directions}
\label{sec:future}

The B8 and B9 negative results suggest that the next gains are more likely to come from stronger supervision and information-preserving sequence modeling than from hard-coded spatial or semantic constraints. Promising directions include: (i) teacher--student self-training using a frozen high-confidence MRI teacher over report-silent cells; (ii) pathology-family specialist heads trained from the same shared encoder while maintaining global evaluation rules; (iii) adaptive or denser slice sampling for focal abnormalities; (iv) sequence-set modeling that can ingest multiple acquisitions per plane without forcing every acquisition into exactly one fluid/structural slot; (v) physical-scale normalization or explicit PixelSpacing features; and (vi) independent external or leaderboard validation before further development decisions are made from the 58-study set.

Any new candidate should be explicitly named before evaluation and compared against B7.1 with the same aligned study-level bootstrap. Target-specific winner selection and ensemble-weight optimization on the current gold set should remain prohibited.

\section{Conclusions}
\label{sec:conclusion}

CNN\_CPC provides an end-to-end framework for weakly supervised multi-sequence knee MRI classification with explicit DICOM handling, conservative report supervision, competition-only representation learning, pathology-query attention, experiment provenance, and paired uncertainty estimation. The strongest measured standalone development model is B7.1, which combines B5 image--report initialization, frozen B6 pathology labels, the globally pooled six-stream Transformer architecture, and four complete passes over all 3,120 active weakly labelled studies. It reaches macro AUC 0.5644802945 on the repeatedly used 58-study development set.

Two subsequent controlled ablations did not improve this result. B8 spatial-token learning reached 0.5300962807. B9 strict semantic routing corrected all identified fluid/structural assignment mismatches but reached 0.5334962669, with paired median difference $-0.0302397961$ relative to B7.1 and only 5.62\% of bootstrap replicates favoring B9. These negative experiments are scientifically useful: they show that smoother optimization, increased spatial detail, and stricter metadata consistency do not necessarily improve study-level macro AUC. The retained conclusion is therefore conservative: B7.1 remains the development champion, while hidden-test and clinical performance remain unknown until evaluated on genuinely independent data.
